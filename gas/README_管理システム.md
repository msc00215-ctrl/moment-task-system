# MOMENT 2026 タスク・スケジュール管理システム

## 初回セットアップ（5分でできる）

### ① Google Apps Script を開く
1. ブラウザで https://script.google.com を開く
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「MOMENT2026_管理」に変更

### ② コードを貼り付ける
1. エディタ左のファイル `コード.gs` をクリック
2. `MOMENT2026_管理システム.gs` の中身を全選択（Ctrl+A）してコピー
3. エディタの中身を全削除してから貼り付け（Ctrl+V）
4. Ctrl+S で保存

### ③ 実行する
1. 上の関数選択欄で `createManagementSystem` を選ぶ
2. ▶ 実行ボタンをクリック
3. 「権限が必要です」→「許可を確認」→ Googleアカウントでログイン → 「許可」
4. 完了！作成されたスプレッドシートのURLが表示される

## 日常使用方法

### タスクの状態を更新する
1. 「📋 全タスク」シートを開く
2. E列（状態）を直接編集
   - 選択肢: `未着手` `対応中` `待機中` `保留` `予定` `調整中` `完了`
3. 上メニュー「🎵 MOMENT管理」→「ダッシュボード更新」でダッシュボードに反映

### 新しいタスクを追加する
「📋 全タスク」シートの末尾行に直接追記（列順は上部参照）

### LINEトークから更新する
1. LINEアプリで対象グループ → ☰ → トーク履歴をバックアップ
2. テキストファイルをPCで開いて全選択コピー
3. 「📱 LINE取込」シートの指定エリアに貼り付け
4. 上メニュー「🎵 MOMENT管理」→「LINE解析実行」
5. 解析結果を確認して「📋 全タスク」に手動追記
